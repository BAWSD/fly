# flight-tracking-frontend

Vite + Vue 3 frontend for the flight tracking platform.

## Quick Start

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`.

## Environment Variables

- `VITE_API_BASE_URL`: API gateway base URL, e.g. `http://localhost:8080`
- `VITE_WS_BASE_URL`: WebSocket base URL, e.g. `ws://localhost:8080`
- `VITE_BAIDU_MAP_AK`: Baidu Map WebGL key
- `VITE_AI_SERVICE_URL`: AI service URL, e.g. `http://localhost:5000`
